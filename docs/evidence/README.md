# Reproducible integration evidence

Evidence in this directory must be generated from real integration runs and must not contain credentials.

- `datahub-context.json` and its `.sha256` sidecar are generated by `python scripts/capture_datahub_evidence.py` only when the provider is `datahub-mcp` and governed resources are returned.
- `arm-inference-benchmark.json` and its `.sha256` sidecar are the normalized output of native Arm run `30822464850`; the adjacent Markdown records the artifact IDs, ZIP digests, methodology, results, and disclosures.
- Arm64 benchmark artifacts are produced by the `container` CI job on a native `aarch64` runner.
- CockroachDB vector-index creation and recall are verified by the `cockroach` CI job.
- Gemini structured output is verified by the secret-masked `gemini` CI job.

The public CI run at https://github.com/Layerrail/cloud-steward/actions/runs/30781828308 passed the Arm64, CockroachDB, and Gemini paths. A separate local run on 2026-08-03 captured live DataHub Core evidence with `search`, `get_entities`, and `get_lineage` after loading the official `showcase-ecommerce` datapack. The corresponding 104-second walkthrough is public at https://youtu.be/xW0RnBrROeA. The public Render deployment remains in disclosed sample mode.

Native Arm inference run https://github.com/Layerrail/cloud-steward/actions/runs/30822464850 passed the FP16 and Q4_0 structural safety gates and published raw and normalized artifacts. The public Render deployment remains x86_64 with Arm local inference disabled.
