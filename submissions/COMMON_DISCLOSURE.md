# Common project disclosure

Cloud Steward is a new standalone Apache-2.0 project started on 2026-08-02 by Oluwamayowa Oladosu.

It shares no source code with LayerRail's pre-existing AGPL-3.0 repository. LayerRail supplied the founder's domain experience and may later be accessed through documented network APIs. The initial user, revenue, and expense figures for Cloud Steward are zero unless the submission provides dated evidence otherwise.

AI assistance was used during implementation. The founder remains responsible for reviewing, testing, documenting, and submitting the resulting work.
